# AI-Assisted Development

Guidance on using AI assistants responsibly in software engineering workflows.

## Scope

- When and how to use AI during design, implementation, and review
- Prompting strategies for engineering tasks
- Verifying and reviewing AI-generated code
- Risks and limitations of AI-assisted development

## Does not belong here

- Tool-specific rule formats → see `rules/` (derived output, not authored knowledge)
- Adapter configuration → see `scripts/`
- General engineering practices → see `engineering/`

This domain covers **how engineers work with AI**, not how AI tools are configured.
