# Copilot instructions

Scaffold for GitHub Copilot instruction layout. **Deployable output** is generated by the Copilot adapter (`ekp-core` pilot).

Do not author Copilot instructions here without a corresponding knowledge document.

Assemble:

```bash
py -3 scripts/assemble/assemble.py --profile ekp-core --clean --verify
```

Copy `dist/ekp-core/copilot/.github/` into the consumer repository root. See [`docs/deployment.md`](../../docs/deployment.md).
