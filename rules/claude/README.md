# Claude Skills and Instructions

Scaffold for Claude Code layout. **Deployable output** is generated by the Claude adapter (`ekp-core` pilot): compact `CLAUDE.md` plus document-grouped `.claude/skills/<skill-id>/SKILL.md`.

Do not author skills here without a corresponding knowledge document. Pathless `.claude/rules/` are not part of Claude v1.

Assemble:

```bash
py -3 scripts/assemble/assemble.py --profile ekp-core --clean --verify
```

Copy `CLAUDE.md` and `.claude/skills/` into the consumer project. Runtime skill invocation is not empirically verified. See [`docs/deployment.md`](../../docs/deployment.md).
