# Cursor Rules

Scaffold for Cursor rule layout. **Deployable output** is generated by the assemble pipeline.

## Generated output

```bash
py -3 scripts/assemble/assemble.py --profile cursor-core --clean --verify
```

Produces `dist/cursor-core/cursor/*.mdc` and `bundle-manifest.json` (gitignored).

Deploy to consumer projects: copy `dist/cursor-core/cursor/` → `.cursor/rules/`.

## Authoring policy

Rules are derived from knowledge documents via `scripts/adapters/cursor/`. Do not author standalone rules here without a corresponding knowledge document.

Format reference: `templates/cursor-rule-template.md`.

See [`docs/adapter-architecture.md`](../../docs/adapter-architecture.md) and [`DEVELOPMENT.md`](../../DEVELOPMENT.md).
